# 文档索引

本目录保存项目的完整说明。根目录的 README 只保留上手所需的最少内容。

| 文档 | 面向谁 | 主要内容 |
|---|---|---|
| [使用指南](usage.md) | 使用者 | 安装、运行转换、查看产物、自动验证、常见操作 |
| [配置参考](configuration.md) | 使用者 | 每个配置项的作用、默认值、可选值和示例 |
| [转换规则](conversion.md) | 使用者、维护者 | 产物里的名字、执行器、几何、碰撞体、材质是怎么来的 |
| [已知限制与排错](limitations.md) | 使用者 | 目前做不到的事情，以及常见问题的排查方向 |
| [开发指南](development.md) | 维护者 | 代码结构、模块职责、测试、扩展方式 |
| [AI 开发笔记](ai-notes.md) | AI 助手、维护者 | 修改代码前值得先了解的事实和注意事项 |

阅读顺序建议：

1. 第一次使用，先看[使用指南](usage.md)。
2. 要调整转换行为，再看[配置参考](configuration.md)。
3. 想弄清楚某个产物为什么长这样，查阅[转换规则](conversion.md)。
4. 遇到报错或结果不符合预期，看[已知限制与排错](limitations.md)。
5. 要修改代码，先读[开发指南](development.md)和 [AI 开发笔记](ai-notes.md)。
